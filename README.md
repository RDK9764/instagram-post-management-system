# Instagram Post Management System

A full-stack Instagram-style post management application.

## Tech Stack

### Frontend
- React
- Axios
- React Router

### Backend
- Spring Boot
- Spring Security
- JWT Authentication
- Hibernate / JPA

### Database
- MySQL

## Features
- User Registration/Login
- JWT Authentication
- Add/Edit/Delete Posts
- Like Posts
- Search by Hashtag
- Sort Posts
- User-specific Authorization

## How to Run

### Backend

```bash
cd backend
mvn spring-boot:run
```

### Frontend

```bash
cd frontend
npm install
npm run dev
```
